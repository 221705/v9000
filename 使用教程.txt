====================================================================
 90HX PCIe 一键解锁（直启版）详细使用教程
 适用包：NVPermissive-DirectBoot（方案 A，推荐）
 文档日期：2026-09-09
====================================================================

本教程是手把手级说明。安装只需三步：关 Secure Boot、右键
install.bat 管理员运行、重启。其余章节供深入了解和排障。

--------------------------------------------------------------------
一、这是什么
--------------------------------------------------------------------
CMP 90HX 等矿卡被厂商锁定为 PCIe 1.1 速率（挖矿用不到带宽）。
装进普通电脑后，游戏、渲染、AI 计算都会受带宽瓶颈拖累。

本包内的 NVPermissiveDirect.efi 是补丁版解锁工具（与原版仅 2 字节
之差），把它注册成固件启动项后，每次开机流程变为：

    主板固件 -> 直启解锁（自动） -> 链式启动 Windows（自动）

全程无需 U 盘、无需按键、无需任何手动操作。

实测结果（2026-09-09 验证机）：开机全程约 1 分 30 秒（含主板自检），
进系统后 GPU-Z 显示 PCIe x16 2.0，解锁成功。

--------------------------------------------------------------------
二、原理简述（为什么不能一次解锁永久生效）
--------------------------------------------------------------------
1.1 锁来自 GPU 芯片内部的熔丝（硬件烧录），每次上电时显卡内部
微码会重新施加 PCIe 1.1 限制。

工具做的事：在 Windows 启动之前的固件层执行——重开链路电源管理、
强制把 PCIe 链路重训练为 Gen2，然后不重启、直接交接给 Windows。

两个推论：
  * 解锁状态只存在于内存（RAM）中，关机断电即失效。所以必须每次
    开机自动执行一次——这正是本包做的事，属正常现象。
  * 没有软件办法永久固化。想永久改只能改 vBIOS/微码，需要破解
    官方签名，存在砖卡风险，不推荐。

--------------------------------------------------------------------
三、前置条件（装之前逐项检查）
--------------------------------------------------------------------
1. Windows 10/11 64 位，且为 UEFI 引导。
   检查方法：Win+R 输入 msinfo32 回车 -> 看"BIOS 模式"一项，
   必须显示 UEFI。若显示"传统/legacy"，本包不可用。

2. Secure Boot 已关闭（操作方法见第四节）。必须关闭，否则固件会
   拒绝执行未签名的解锁工具。

3. 建议关闭/暂停 BitLocker 驱动器加密。修改引导链在极少数情况
   下会触发 BitLocker 恢复模式。若从未开过 BitLocker 则忽略本条。

4. 显卡驱动已装好，系统能正常进桌面。

5. 推荐保留原版 U 盘工具在手上（紧急救援用，见第九节）。

--------------------------------------------------------------------
四、如何关闭 Secure Boot
--------------------------------------------------------------------
1. 重启电脑，开机时连续按 Del 或 F2 进入 BIOS/UEFI 设置界面
   （不同主板按键不同，常见还有 F10/F12，可查主板说明书）。
2. 找到 Secure Boot 选项，常见位置：
     Security 菜单 / Boot 菜单 / Advanced -> Windows OS Configuration
3. 把 Secure Boot 设为 Disabled（关闭）。
4. 按 F10 保存并退出（个别主板是 F4 或其他，界面有提示）。
5. 重启后回到 Windows 桌面，继续安装。

若找不到 Secure Boot 选项：某些主板需要先把 CSM（兼容性支持模块）
关闭，或把 OS Type 从 "Windows UEFI mode" 切换到其他模式后才会
显示该选项。

--------------------------------------------------------------------
五、安装步骤（手把手）
--------------------------------------------------------------------
1. 把整个文件夹 NVPermissive-DirectBoot 拷贝到目标电脑任意位置
   （桌面、D 盘都行）。文件夹内文件一个都不能少、不要改文件名。

2. 确认 Secure Boot 已关闭（第四节）。

3. 右键 install.bat -> 以管理员身份运行。
   看到绿色 [OK] 输出，结尾出现 "DONE" 即安装成功。
   全程约 5 秒，安装脚本会自动：
     - 校验 4 个工具文件的 SHA256 哈希（防拷贝损坏或被篡改）
     - 检测管理员权限、UEFI 模式、Secure Boot 状态
     - 挂载 ESP 分区并复制工具文件（绝不触碰 Windows 引导文件）
     - 注册固件启动项，并把启动顺序设为：
         ① 直启解锁（快）
         ② Shell 解锁（备用，功能相同，慢 1~5 秒）
         ③ Windows Boot Manager（永远保留，兜底进系统）
         ④ 原有其他启动项不变
   重复运行 install.bat 是安全的（幂等）：已装过的组件会被复用
   而不是重复创建。

4. 重启电脑。什么都不用按，等待自动进入 Windows。

5. 打开 GPU-Z 验证解锁成功（见第六节）。

双保险设计：万一 ① 直启项启动失败，主板固件会自动落到 ② Shell
解锁项（照常解锁），② 再失败则落到 ③ Windows（正常进系统，只是
本次未解锁）。也就是说，最坏情况只是"本次没解锁"，不会开不了机。

--------------------------------------------------------------------
六、如何验证解锁成功
--------------------------------------------------------------------
1. 打开 GPU-Z（没装就下载安装，免费小工具）。
2. 主界面看 "Bus Interface" 一行：
     解锁成功：PCIe x16 2.0 @ PCIe x16 2.0
     未解锁  ：PCIe x16 2.0 @ PCIe x16 1.1
   括号后面是当前实际运行速率。注意显卡空闲时会自动降速，点这一行
   右边的 "?" 问号按钮可以跑个渲染负载，让显卡升到实际速率再读。
3. 更直观的验证：跑 3DMark 或游戏对比帧数。
4. 确认无误后，本机部署完成。什么都不用再管，以后每次开机自动解锁。

--------------------------------------------------------------------
七、测试模式（第一次装、心里没底时用）
--------------------------------------------------------------------
正式安装前想先"试一次、不设默认"，按此流程：

1. 右键 install_test.bat -> 以管理员身份运行。
   它会把直启项追加到启动顺序末尾，不改当前默认启动项。

2. 重启，开机时连续按启动菜单快捷键（常见 F8 / F11 / F12，
   看主板型号），在弹出的启动菜单中选择 "NVPermissive Direct Boot"。

3. 正常进系统 + GPU-Z 显示 2.0 = 测试通过。
   然后右键 install.bat 运行一次，把直启项置顶为默认，完成。

4. 若测试失败（启动卡死）：长按电源键强制关机，再开机时不按启动
   菜单键，机器会照常从原来的默认项进 Windows。进系统后运行回滚
   或联系排查（见第九节）。

--------------------------------------------------------------------
八、回滚 / 卸载
--------------------------------------------------------------------
回滚脚本也在文件夹里，两种力度：

【只删直启项】右键 Rollback-DirectBoot.bat -> 以管理员身份运行
  效果：直启项和补丁文件被删除，机器回到 Shell 解锁链（仍会自动
  解锁，开机慢 1~5 秒，功能完全相同）。

【全部删除】需要带参数 -Full：
  1. 打开文件夹，在地址栏输入 cmd 后回车（黑窗口会在此文件夹打开）
  2. 输入：Rollback-DirectBoot.bat -Full  然后回车
  效果：直启项 + Shell 链 + 全部工具文件删除，回到纯 Windows 引导，
  卡回到 1.1 锁定状态。系统完全恢复安装前的样子。

【紧急救援】如果已经开不了机：
  1. 插上原版 U 盘工具开机。U 盘里的工具会照常解锁并链式启动
     Windows，让你先进系统。
  2. 进系统后运行上述回滚脚本即可复原。

--------------------------------------------------------------------
九、常见问题排查（FAQ）
--------------------------------------------------------------------
Q1：重启后进不了系统？
A：引导顺序里 Windows Boot Manager 永远保留着，主板固件会自动
   落到它正常进系统（只是本次未解锁）。进系统后重跑 install.bat
   或按第八节回滚。

Q2：GPU-Z 还是显示 1.1？
A：按顺序排查：
   ① 是否最近做过 Windows 大版本更新？更新可能重置引导顺序，
      重跑一次 install.bat 即可（幂等，安全）。
   ② 确认 Secure Boot 是关闭状态；开着时解锁项会被固件拒绝执行，
      静默落到 Windows 项，表现为"能进系统但没解锁"。
   ③ 在 BIOS 启动菜单里确认 "NVPermissive Direct Boot" 项存在且
      排在 Windows Boot Manager 前面。

Q3：显卡驱动报 Code 43？
A：极少数情况（工具日志自述）。先跑 -Full 回滚，观察是否恢复。
   若回滚后恢复正常，则此卡与本工具不兼容，用回原版 U 盘方案。

Q4：忘了关 Secure Boot 就装了怎么办？
A：没有副作用。解锁项会被拒绝执行，机器自动落到 Shell 项或
   Windows 项正常进系统。去 BIOS 关掉 Secure Boot 再重启即可，
   不用重装。

Q5：开机比装之前慢了？
A：直启项本身很快，实测整机开机全程约 1 分 30 秒（含主板自检）。
   如果比装之前明显慢很多，检查启动顺序是否变成 Shell 项在前
   （跑一遍 install.bat 恢复直启置顶）。

Q6：双显卡机器（例如 RX 580 2048SP + 90HX）能用吗？
A：能。工具只对 N 卡（90HX）生效，A 卡不受影响。90HX 没有显示
   输出口，画面一直由 RX 580 输出，解锁前后显示都不受影响。

Q7：以后不想要了，能恢复原样吗？
A：能。按第八节跑 -Full 回滚，启动项、文件全部清除，系统回到
   安装前的状态，卡回到 1.1 锁定。

Q8：可以在多台机器上装吗？
A：可以，无数量限制。每台机器各自拷贝整个文件夹、各自运行
   install.bat 即可，机器之间互不影响。

--------------------------------------------------------------------
十、日常维护与注意事项
--------------------------------------------------------------------
  * Windows 大版本更新（如 23H2 -> 24H2）可能重置引导顺序，
    导致解锁失效。表现为 GPU-Z 回到 1.1。处理：重跑 install.bat。
  * Secure Boot 必须保持关闭状态，不要随手在 BIOS 里重新打开。
  * BitLocker 若已启用，建议保持关闭/暂停状态。
  * 解锁是内存级：每次开机由工具重新执行，断电即失效，属正常。
  * 建议在每台装过的机器上都保留一份本包文件夹（回滚要用）。
