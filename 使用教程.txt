NVPermissive Compat 使用教程（手把手）
======================================

【这是什么】
90HX 等 CMP 矿卡出厂被锁 PCIe 1.1，NVPermissiveEFI 工具在开机时
临时解锁到 Gen2 x16。解锁状态在显卡 RAM 里，每次开机都要重新跑
一遍工具，所以叫"开机解锁"。本包是兼容性加强版。

【原理】
开机时 UEFI 固件按启动顺序依次尝试启动项。本包把标准启动项
{bootmgr} 的路径指向解锁工具：
  开机 → 固件跑 {bootmgr} → 实际执行的是解锁工具 → 工具解锁
  → 工具自己找到 Windows 引导文件并启动它 → 进系统（已解锁）。
如果工具失败（任何报错），工具返回错误码，固件自动落到第二个
启动项（兜底）→ 普通 Windows（没解锁，但能正常用）。
所以最坏情况也只是"没解锁"，永远不会开不了机。

【前置检查】
  1. 目标机器必须 UEFI 启动（GPT 系统盘 + winload.efi）
  2. BIOS 里 Secure Boot 必须关闭
  3. 显卡供电线插满、插槽识别正常（设备管理器能看到卡）

【安装步骤】
  1. 把整个文件夹拷到目标机器（路径别太深，英文路径最好）
  2. 右键 Install-Compat.bat → 以管理员身份运行
  3. 屏幕显示 "[OK] ..." 一路走完，最后 DONE
     （脚本顺序：校验文件→挂载ESP→备份快照→建兜底项→清理旧
       启动项→排顺序→最后才改 {bootmgr}，中途任何一步失败都
       不会碰 {bootmgr}，可放心重跑）
  4. 重启。开机黑屏几秒后出现工具输出（正常），然后进 Windows
  5. 打开 GPU-Z → 总线接口显示 "PCIe x16 2.0" = 解锁成功
     （空闲时可能显示 1.1，负载/点旁边问号重测会回 2.0）

【失败演练（建议做一次）】
  目的：证明兜底可靠。
  1. 挂载 ESP 后把 \EFI\NVPermissive\NVPermissiveCompat.efi
     改名成 .off
  2. 重启：应正常进 Windows（无解锁，PCIe 1.1）
  3. 改名回来。若这一步进不去系统，说明兜底有问题，回滚重装。

【U盘直启（免安装）】
  把文件夹内容拷到 FAT32 U 盘根目录 → 目标机器开机选 UEFI 启动
  该 U 盘。屏幕会依次显示：
    [0/3] PCI 设备列表 —— 找 10DE 开头的行确认显卡被枚举
    [1/3] 跑 Compat → 解锁 → 自动链启 Windows
    [2/3] 找不到 Compat 时跑旧版工具
    [3/3] 还不行就直接启动 Windows
  这是给"装了没反应"的机器做现场诊断用的：
  - pci 列表里没有 10DE 行 → 主板没枚举到卡（BIOS 挖矿模式/
    CSM/换槽/换 riser）
  - 有 10DE 行但提示 no supported device → 完全断电重试
  - 报 FAILED(-1)/(-3) → 看 README 对照表第六条

【常见问题】
  Q: 安装完开机直接进 Windows，没看到工具画面？
  A: {bootmgr} 没排第一或没改到。重跑 Install-Compat.bat，
     或 bcdedit /enum {fwbootmgr} 看 displayorder 第一项。

  Q: 工具画面出现了，但 GPU-Z 还是 1.1？
  A: 对照 README 第六节的失败对照表排查。重点：完全断电重试、
     换槽、关 ASPM。

  Q: 换显卡/换主板后要重装吗？
  A: 工具对硬件自适应（桥自动枚举），不用重装。但 Windows 大
     版本更新可能重置启动顺序，重跑一次 Install-Compat.bat 即可。

  Q: 想彻底不用了？
  A: 右键 Rollback-Compat.bat 管理员运行（-Full 连文件一起删）。
